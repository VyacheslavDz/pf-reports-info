Программа для внутренней работы

Из Planfix — в готовый отчет.

PF Reports работает на компьютере владельца: получает запрос из Planfix, формирует отчет по заданным правилам и создает Google Таблицу в подключенном аккаунте.

Как это работает

  1. Уполномоченный пользователь нажимает кнопку в задаче Planfix.
  2. Локальная программа получает необходимые данные и проверяет расчет.
  3. Создает Google Таблицу и возвращает ссылку в исходную задачу.

Права просмотра самой таблицы определяются отдельно в Google Drive. Созданные отчеты по умолчанию доступны только владельцу.

Для чего нужен вход Google

PF Reports использует Google Drive API для создания файлов отчетов и Google Sheets API для проверки записанных значений. Запрашивается разрешение drive.file: работа только с файлами, созданными приложением или явно предоставленными ему пользователем. Программа не запрашивает доступ ко всему Диску, Gmail или контактам.

Этот сайт содержит только информацию о программе. Вход Google выполняется отдельно при настройке локального приложения; сайт не принимает пароли, данные отчетов или ключи доступа.

Кто использует программу

PF Reports — внутренний инструмент 1C Profit для владельца и отдельно уполномоченных сотрудников. Публичная регистрация пользователей не предоставляется. Программа не является продуктом Google или Planfix.
