Политика конфиденциальности

Эта политика описывает обработку данных локальной программой PF Reports, используемой 1C Profit для внутренних отчетов. Контакт владельца и поддержки: 1cprofit2017@gmail.com.

Какие данные используются

Из Planfix программа получает разрешенные владельцем сведения задач, комментарии с запросами отчета и учетные записи консультаций, необходимые для выбранного расчета. Обрабатываются сведения о работах, клиентах, исполнителях, времени и суммах в пределах правил отчета.

Через Google API программа создает файлы отчетов, читает их идентификаторы, названия, ссылки, служебные свойства и содержимое созданных таблиц для проверки результата и поиска уже готового отчета. Используется только разрешение https://www.googleapis.com/auth/drive.file. Оно ограничивает доступ файлами приложения и файлами, которые пользователь явно предоставил приложению; доступ ко всем файлам аккаунта не запрашивается.

Для работы сохраняются разрешения доступа Google, сведения о выполненных запросах и соответствие запроса готовому отчету. Пароль Google приложение не получает и не сохраняет.

Зачем и куда передаются данные

Данные используются для подготовки запрошенного отчета, проверки значений, предотвращения повторной сборки и возврата ссылки в исходную задачу Planfix. Сформированный файл передается в Google для создания Google Таблицы. Ссылка и статус выполнения передаются обратно в Planfix и доступны в соответствии с правами этой задачи.

Для управления последовательностью локальных действий используется OpenAI через подключенный аккаунт ChatGPT. В этот сервис передаются инструкции, правила расчета и краткие результаты локальных инструментов. Исходные описания консультаций остаются в локальном обработчике. Данные, прочитанные из Google API при проверке таблицы, не передаются в ИИ. PF Reports не использует данные Google для обучения моделей, рекламы, продажи данных или оценки кредитоспособности.

PF Reports использует данные, полученные через Google API, в соответствии с Google API Services User Data Policy, включая требования Limited Use. Иные передачи данных возможны только по отдельному указанию владельца либо когда это требуется применимым законом.

Хранение и защита

Программа выполняется на компьютере владельца. Исходные выгрузки, промежуточные файлы, результаты и журнал обработки сохраняются локально. Секреты доступа защищены средствами Windows для текущего пользователя. Обмен с сервисами выполняется по HTTPS. Google Таблицы хранятся в аккаунте пользователя и создаются без публичного доступа. Доступ к компьютеру и последующее предоставление доступа к таблицам контролирует владелец.

Автоматическое удаление по истечении срока не настроено: локальные материалы и Google-файлы сохраняются до удаления владельцем. Отзыв разрешения Google прекращает дальнейший доступ, но сам по себе не удаляет ранее созданные отчеты или локальные копии.

Как отозвать доступ и удалить данные

Доступ PF Reports можно отозвать в настройках подключений Google. Для прекращения обработки также остановите локальную программу и ее автозапуск. Созданные таблицы удаляются владельцем в Google Drive; локальные выгрузки, отчеты и сохраненный доступ удаляются на его компьютере. По вопросам удаления и состава локальных материалов обратитесь по указанному выше адресу поддержки.

Посещение сайта и изменения политики

Информационные страницы размещаются на GitHub Pages. На сайте нет форм ввода, аналитических счетчиков и собственных скриптов. GitHub обрабатывает технические сведения о посещениях, включая IP-адрес, по своей политике конфиденциальности.

Актуальная редакция размещается на этой странице с датой изменения. Перед использованием данных для новой цели или расширением разрешений владелец должен быть уведомлен и дать необходимое согласие.
